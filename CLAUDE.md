# vibroplity

Микросайт **Виброплиты.by** — аренда виброплит 60–500 кг и вибротрамбовок в Минске.
Один из микросайтов Стройрента (как trambovka, teplopushka, osushitel…). Стек как у Теплопушки:
**Astro 7 (статика), без JS-фреймворков и GSAP**; дизайн свой — «грунт и сейсмограф».

## Команды

```bash
npm ci            # Node ≥ 22.12 (см. .nvmrc)
npm run dev       # http://localhost:4321
npm run build     # → dist/ (обычные .html, как у остальных микросайтов)
npm run preview   # посмотреть собранный dist/
./deploy_server.sh  # залить на sites-legacy и собрать там
./tests/send_php_test.sh   # send.php против заглушек CRM и Telegram (без сети)
node tests/e2e.cjs         # приёмка в браузере (после npm run preview): форма, калькулятор, reduced-motion
```

Astro закреплён на `7.3.8` (точная версия), как на Теплопушке: 7.4+ требует Node ≥ 22.23.4.
Поднимать вместе с Node.

Страницы: `/`, задачи — `/vibroplita-pod-plitku.html`, `/vibroplita-dlya-otmostki.html`,
`/vibroplita-dlya-parkovki.html`, `/vibroplita-dlya-shchebnya.html`; классы веса —
`/legkie-vibroplity.html`, `/srednie-vibroplity.html`, `/tyazhelye-vibroplity.html`;
`/kontakty.html`, `/privacy.html`, `404.html`, `sitemap.xml`. Список для меню и карты сайта —
`src/data/pages.ts`.

**Акцент — янтарь `#e8a838`, задаётся в одном месте:** `--signal-rgb` в `global.css` (и `--d2`
рядом). Кнопки, «зебра», плотномер, canvas (читает цвета из CSS) — всё от него. Исключения:
`public/favicon.svg` и `public/og.png` — менять отдельно (og.png снят с первого экрана,
1200×630, reduced-motion, без шапки).

**Шкала плотности** `--d0…--d3` (рыхлый → средний → плотный → уплотнён) — сквозной приём:
слои на первом экране, плотномер, калькулятор, шкала веса, шаги.

**Темы.** Тёмная («асфальт») — по умолчанию, светлая («песок», `#efe9df`) — сама по
`prefers-color-scheme: light`. Блоки «прибора» помечены `.dark-zone` и тёмные в обеих темах:
первый экран, калькулятор, формы заявки, всплывающая форма, картинки каталога, разрез на страницах
задач, 404. Цвета — только через переменные `global.css`.

**Бюджет скриптов:** главная ≤ 10 КБ gzip (сейчас ≈ 8,7), остальные ≤ 5 КБ (≈ 3). Поэтому
калькулятор есть только на главной; со страниц задач на него ведёт ссылка с предустановкой
`/?task=otmostka&material=pgs&t=25#calc`.

**Первый экран:** по высоте содержимого, H1 ≤ 52 px, кнопки и чипы видны на 1440×820. Canvas —
≤ 1 px на CSS-пиксель, пауза вне экрана и в фоновой вкладке, при reduced-motion — один кадр.

## Откуда данные

- **Парк и цены** (`plates.ts`, `calc.ts`) — основной сайт Стройрента (`val1180/stroyrent`):
  `database/seeds/offers-seed-2026-09-05.json` (категории 27 и 130) и характеристики по классам
  веса из `database/seeds/legacy/items.json`. Одна карточка каталога = одна ценовая группа CRM.
  Остатки на сайт не выводим — только «в наличии»; поле `units` нужно калькулятору, чтобы не
  предлагать две одинаковые машины, когда в парке одна. Больше двух — «комбинация через менеджера».
- **Фото** — `database/seeds/photos/vibroplity-{35-40,60,110,140,180}.jpg`, белый фон убран.
  Для групп 20, 30, 50, 80 руб. и вибротрамбовки фото нет — силуэты.
- **Текст «как выбрать»** — по смыслу из `category-texts.json` (кат. 27), переписан.
- **Бензин АИ-92, заправленными; доставка по Минску и области; от 120 кг — прицеп или доставка** —
  взято с trambovka.by (тот же бизнес), см. «Проверить до запуска».
- **Telegram, пункты выдачи, режим работы** — общие для микросайтов. Телефон убран 25.10 по просьбе владельца («пока что»): вернуть — `phone`/`phoneHuman` в `site.ts` и ссылки в шапке, подвале, контактах, JSON-LD (см. коммит удаления).

## ⚠️ Проверить до запуска

- **Цены группы 35–40 руб.** — в CRM одна группа (MS 90, MS 100, VP-120K, MS 140); в старом
  каталоге 90 кг = 35, 120 кг = 40, **140 кг = 50**. На сайте везде «35–40 руб.» — уточнить и,
  если надо, разбить карточку `p90-140` в `plates.ts` и машины `m90/m120/m140` в `calc.ts`.
- **Характеристики Scheppach HP 1100S и Сплитстоун VS-246 E12** — в каталоге пусто; на карточках
  «уточнит менеджер», в калькуляторе не участвуют. Нужны вес, глубина, плита, производительность.
- **Привязка характеристик к моделям** — по классам веса старого каталога (ориентир). MS 260 —
  по классу «300 кг реверсивная».
- **Бензин:** на сайте «выдаём заправленными АИ-92» (FAQ главной) — так написано на trambovka.by;
  подтвердить для этого сайта.
- **Доставка тяжёлых (300–500 кг):** на сайте «доставляем по Минску и области, стоимость назовёт
  менеджер» — подтвердить, что возим, и при желании вписать цену.
- **Пересечение с trambovka.by:** тот же бизнес и те же плиты на другом домене. Тексты написаны
  заново (не копировать оттуда!), но Яндекс может посчитать сайты аффилиатами и показывать по
  запросу один. Решить, как разделить семантику (например, trambovka — страницы по весу «аренда
  виброплиты 60 кг…», vibroplity — задачи), и не ставить одинаковые title/description.
- **E-mail** `info@vibroplity.by` — ящик не заведён (или заменить на рабочий) — `SITE.email`.
- **Аналитика:** создать Метрику и GA4 для vibroplity.by и вписать в `SITE.analytics`. Пусто —
  скрипты не грузятся. `leads.ts` шлёт цели `lead_open` / `lead_sent`.
- **CRM:** добавить сайт `vibroplity` в `config/leads.php` → `sites` (репозиторий CRM).
- **Фото:** нет фото для групп 20 (Scheppach), 30 (MS60/VP-65K), 50 (VS-246), 80 (Сплитстоун
  309 / Splitstone 300) и виброноги с ковриком; фото групп 110 и 140 в каталоге одинаковые.
  Положить `src/assets/plates/<id>.webp` (id — в `plates.ts`; прозрачный фон, ~600 px).
- **Коэффициенты калькулятора** (`LAYER_K`, `PASSES`, `WORK_EFF`, данные виброноги) — ориентир;
  поправить по опыту менеджеров.
- **Кросс-ссылки:** teplopushka.by — в советах и подвале (зимой отогреть грунт).
  progrevbetona.by не ставить, пока домен не куплен.

## Заявки

Форма → `POST /send.php { text, hp }` → `{ ok }`. `send.php` — копия с Теплопушки (а та — с
trambovka.by), отличается только кодом сайта `vibroplity` и проверкой Origin (`vibroplity.by`).

- Блок **`crm-lead v1`** в `send.php` одинаковый во всех микросайтах — менять только во всех сразу.
- Заявка сначала уходит в CRM (`crm_leads_url` в `tg_config.php`), при любом сбое — в Telegram
  (личный чат + группа «Лиды»). `tg_config.php` лежит в `public/` только на сервере, в git не попадает.
- Пока CRM не знает сайт `vibroplity`, она отвечает 422 и заявки идут запасным путём в Telegram.
- В заявке: телефон, имя, задача, площадь, «когда нужна», выбранная модель и строка калькулятора
  (задача, материал, толщина, площадь → слои, проходы, часы, сутки), UTM и реферер.
- Ловушка для ботов — скрытое поле `website` (`hp`).

## Запуск на сервере (sites-legacy, 185.251.38.105)

1. DNS `vibroplity.by` и `www` → 185.251.38.105 (домен ещё покупается).
2. `/srv/sites/vibroplity/src`, конфиг nginx через `/srv/sites/conf/gen.py`, сертификат certbot.
3. `/srv/sites/build.sh`: `npm ci && npm run build` в `dist/`, Docker-образ node **≥ 22.12**
   (как для Теплопушки).
4. Положить `public/tg_config.php` — иначе заявки не уйдут.
5. Добавить `vibroplity` в CRM (`config/leads.php` → `sites`).
6. Деплой из CI — секрет `SITES_SSH_KEY` в настройках репозитория; без него `./deploy_server.sh`.

## Проверка перед пушем

`npm run build` без ошибок, `./tests/send_php_test.sh`. Визуально — `npm run preview`, затем
`node tests/e2e.cjs`; пройти главную (калькулятор, «Забронировать»), страницы задач и классов
в тёмной и светлой теме на 1440 и 390 px — без горизонтальной прокрутки.
